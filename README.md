# REVERSEX

### Reverse Connection Automation & Testing Framework

**REVERSEX** is a Bash-based cybersecurity college project
designed for authorized network testing and lab demonstrations.

## Features

- Automated TCP connectivity testing
- IP and port validation
- Netcat listener monitoring
- Connection activity logging
- Colored terminal interface
- Dependency checking

## Technologies Used

- Bash Scripting
- Kali Linux
- Netcat
- TCP/IP Networking
- Metasploit Framework (lab integration)

## Platform

Kali Linux
